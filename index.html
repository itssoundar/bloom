What it does

Everything between spotting it and filing it.

Bloom folds the screenshot → crop → annotate → export → paste loop into a single panel in your browser toolbar.

01

Capture from the toolbar

Whole page, a scrolling region, or one element — triggered from where you already are, without leaving the tab.

02

Mark it up in place

Arrows, boxes, freehand marker, and typed notes — drawn on the live page, before anything gets flattened.

03

Arrives as vector layers

Each frame and stroke lands in Figma as an editable path. Drag an anchor, change a stroke weight, resize without softening an edge.

04

Keep a local copy

Pull down a PNG or SVG whenever you need the capture somewhere other than Figma. No separate export step.

05

Paste it anywhere

Drop a marked-up capture into Slack, Notion, a Jira ticket, or an email — same panel, same shortcut.

06

Nothing to install but Bloom

No terminal, no local server, no dependency to keep current. The conversion runs on our side.

The sequence

Four steps, one continuous motion.

From cursor to canvas without a single export dialog in between.

STEP 01

Capture

Open Bloom from the toolbar and pick viewport, region, or a single element.

STEP 02

Mark

Annotate on top of the live page. Nothing is rasterized while you work.

STEP 03

Send

Choose a Figma file and frame. Bloom places the capture there directly — no copy-paste.

STEP 04

Edit

Every stroke is a native path. Reshape it as if you had drawn it in Figma yourself.

Why it matters

Most capture tools hand you a picture. Bloom hands you geometry.

When a stroke leaves your browser, Bloom doesn't flatten it. Every mark is resolved into anchor points and Bézier curves before it ever reaches the canvas.

✕

A pasted screenshot is one flat image. The annotations are baked in — you can't move an arrow, and it softens the moment anyone zooms.

✓

A Bloom capture is a real Figma frame. The markup sits on its own layer, selectable and editable independently.

✓

Grab a single anchor and drag it. Recolor one stroke. Delete one arrow. Nothing else in the frame shifts.

Infrastructure

Server-side by design. Nothing running on your machine.

Bloom isn't a local build tool wearing a browser icon. The extension is a thin capture layer; everything after that happens on our infrastructure.

// no terminal

No command line, ever

Nothing to run before Bloom works — no build script, no local server. Install the extension and open the panel.

// no local deps

No dependencies to manage

Vector conversion and the Figma connection both run on our servers. Your machine never needs a runtime, a library, or an update.

// always current

One version, everywhere

Because the logic lives server-side, everyone on the team is on the same build. No "works on my machine."
